# Beginner C++ Calculator

A simple beginner-level calculator built with C++.

## Features
- Addition
- Subtraction
- Multiplication
- Division
- User input for two numbers
- Menu selection using a `switch` statement
- Invalid menu choice handling
- Decimal number support using `double`

## Concepts Practiced
- Variables and data types
- `cin` and `cout`
- Arithmetic operators
- `switch` statements
- `case` and `default`
- Basic program structure

## Purpose
This project was created as a beginner C++ practice project to strengthen my understanding of programming fundamentals.
